# 访谈分析 Interview Analysis

## 输入
一场访谈的转写文本,建议按发言切分,每行一条陈述。

## 分析方法
1. 用 `research_synthesize` 做初筛(主题聚类 + 痛点抽取)。
2. 对 `painPoints` 中 `severity=2` 的条目,要求 agent 还原**上下文**:用户当时在做什么、卡在哪一步。
3. 标注每条发现的可行动信号:
   - **阻断型**(无法完成任务)→ 高优先级
   - **摩擦型**(能完成但难受)→ 中优先级
   - **期待型**(主动提的需求)→ 机会型

## 输出格式
> 发现:[一句话]
> 原话:"..."
> 类型:阻断 / 摩擦 / 期待
> 建议:接下来可验证的最小动作

## 注意
- 不要美化用户原话;保留口语化表达更有说服力的细节。
- 区分"个例"与"共性":单场访谈里的信号需在合成阶段用更多样本验证。
