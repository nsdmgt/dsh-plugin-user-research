# 用户画像构建 Persona Build

## 画像要素(每条画像至少包含)
- **角色**:如"增长期产品经理""新手设计师"(来自素材中的身份自述)
- **目标**:他要用产品完成什么
- **痛点**:最高频、最痛的 1–3 条(引用原话)
- **场景**:典型使用时刻(通勤 / 周报 / 上线前)

## 构建步骤
1. `research_synthesize` 的 `personas` 给出了角色候选与信号计数。
2. 对每个高 `mentions` 角色,让 agent 从 `painPoints` 中筛选属于该角色的条目。
3. 若素材中无明确身份自述,诚实标注"画像依据不足,按行为聚类推断"。

## 反模式
- 不要编造素材里没有的 demographics(年龄、收入)——定性研究不支撑。
- 画像数量控制在 3–5 个,过多等于没分。
