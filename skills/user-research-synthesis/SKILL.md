# 用户研究合成 User Research Synthesis

## 何时使用
- 手头有一堆定性素材(访谈转写、问卷开放题、客服记录、观察笔记),需要提炼结论
- 需要向团队交付"用户画像 / 痛点 / 机会点"而非原始流水

## 标准流程
1. **收集素材**:把笔记汇总到一个文件(`.txt` / `.md` / `.csv`),放到 dsh 工作区。
2. **调用工具**:`research_synthesize(filePath=..., maxPersonas=5, maxOpportunities=5)`。
3. **复核输出**:
   - `personas` — 推断出的角色及其诉求信号
   - `painPoints` — 抽出的痛点原话(带主题与严重度)
   - `opportunities` — 按信号强度排序的机会点(含评分口径)
4. **二次追问**:让 agent 基于某条机会点展开"为什么""怎么做",形成结论报告。

## 质量准则
- 痛点必须**引用原话**,不替用户"总结"成结论(避免幻觉)。
- 机会点评分 = 信号条数 × 1 + 显式痛点条数 × 2;评分高不代表该做,需结合业务判断。
- 若素材过少(语句 < 10),明确提示结论置信度低,建议补充样本。

## 配合模板
- `templates/interview-script.md` — 访谈提纲
- `templates/synthesis-canvas.md` — 合成画布(记录输出)
